# sub_chat 사용자 시나리오

이 문서는 sub_chat 애플리케이션의 주요 사용자 시나리오를 설명합니다.

---

## 목차

1.  **신규 사용자 온보딩**
2.  **지하철 채팅방 검색 및 참여**
3.  **채팅 참여 및 상호작용**
4.  **채팅방 퇴장 (수동 및 자동)**
5.  **이전 채팅방에 다시 연결**
6.  **임시 채팅방 사용**
7.  **프로필 관리**

---

### 1. 신규 사용자 온보딩

**Actor:** 처음으로 앱을 사용하는 사용자

**Goal:** 계정을 생성하고 앱 사용에 필요한 권한을 설정하여 기본 채팅 목록 화면에 접근한다.

**시나리오:**

1.  사용자가 앱을 다운로드하고 처음 실행한다.
2.  로그인 화면이 나타나면, 사용자는 'Google로 로그인' 버튼을 탭한다.
3.  Google 계정 선택 창이 나타나고, 사용자는 자신의 계정을 선택하여 인증을 완료한다.
4.  로그인에 성공하면 앱에서 위치 정보 접근 권한을 요청하는 팝업이 나타난다.
5.  사용자는 '앱 사용 중에만 허용' 또는 '항상 허용'을 선택하여 권한을 부여한다.
6.  권한 설정이 완료되면, '채팅방 목록' 화면으로 이동한다.
7.  초기에는 근처에 감지된 지하철이 없으므로 "근처에 열차가 없습니다" 라는 메시지가 표시될 수 있다.

---

### 2. 지하철 채팅방 검색 및 참여

**Actor:** 지하철에 탑승 중인 기존 사용자

**Goal:** 현재 타고 있는 지하철의 채팅방을 찾아 대화에 참여한다.

**시나리오:**

1.  사용자가 지하철역 근처 또는 지하철 내부에서 앱을 실행한다.
2.  앱이 자동으로 사용자의 위치를 기반으로 100m 이내에 있는 지하철 열차를 검색한다.
3.  '채팅방 목록' 화면의 'LIVE 지하철 채팅' 섹션에 감지된 열차 목록이 나타난다.
    -   각 항목에는 노선, 행선지, 현재 역, 사용자와의 거리가 표시된다. (예: `2호선 | 성수행 | 강남역 (50m)`)
4.  사용자는 목록에서 자신이 탑승한 열차의 채팅방을 탭한다.
5.  '채팅방' 화면으로 이동하며, 해당 열차의 다른 승객들이 나눈 대화를 볼 수 있다.

---

### 3. 채팅 참여 및 상호작용

**Actor:** 채팅방에 참여 중인 사용자

**Goal:** 메시지를 보내고 다른 사용자의 메시지를 실시간으로 확인하며 소통한다.

**시나리오:**

1.  사용자가 '채팅방' 화면 하단의 입력 필드에 메시지를 입력한다.
2.  '보내기' 버튼을 탭하여 메시지를 전송한다.
3.  자신이 보낸 메시지가 채팅 화면에 즉시 표시된다.
4.  다른 사용자가 보낸 메시지도 실시간으로 화면에 나타난다.
5.  사용자는 다른 사용자의 프로필 사진을 탭하여 차단 또는 신고할 수 있는 옵션을 확인한다.

---

### 4. 채팅방 퇴장 (수동 및 자동)

**Actor:** 채팅방에 참여 중인 사용자

**Goal:** 채팅방에서 나가거나, 열차에서 멀어져 자동으로 퇴장 처리된다.

**시나리오 (수동):**

1.  사용자가 채팅방 화면의 '뒤로 가기' 또는 '나가기' 버튼을 탭한다.
2.  '채팅방 목록' 화면으로 돌아간다.

**시나리오 (자동):**

1.  사용자가 하차하여 열차와의 거리가 100m 이상 멀어진다.
2.  앱이 15분 주기로 위치를 확인하고, 거리가 멀어진 것을 감지한다.
3.  처음 감지 시 "열차와 멀어지고 있습니다. 계속 멀어지면 채팅방에서 자동으로 나가게 됩니다." 라는 경고 알림이 표시된다.
4.  이후에도 계속해서 거리가 멀어진 상태로 다음 위치 확인 주기(15분 후)가 되면, 앱은 사용자를 채팅방에서 자동으로 퇴장시킨다.
5.  사용자에게 "채팅방에서 퇴장했습니다." 라는 알림이 표시되고 '채팅방 목록' 화면으로 이동된다.

---

### 5. 이전 채팅방에 다시 연결

**Actor:** 이전에 채팅방에 참여했던 사용자

**Goal:** 앱을 다시 켰을 때 이전에 마지막으로 참여했던 채팅방에 빠르게 다시 접속한다.

**시나리오:**

1.  사용자가 이전에 특정 채팅방(예: `2호선 | 성수행`)에 참여했다가 앱을 종료했다.
2.  사용자가 앱을 다시 실행한다.
3.  '채팅방 목록' 화면 상단에 "마지막 채팅방에 다시 연결: 2호선 | 성수행" 이라는 알림 바가 표시된다.
4.  사용자가 이 알림 바를 탭한다.
5.  즉시 해당 채팅방으로 다시 연결되어 대화를 이어갈 수 있다.

---

### 6. 임시 채팅방 사용

**Actor:** 위치 기반 채팅 외에 일반적인 대화를 원하는 사용자

**Goal:** 특정 위치에 종속되지 않는 '임시' 채팅방에 참여하여 자유롭게 대화한다.

**시나리오:**

1.  사용자가 '채팅방 목록' 화면의 '일반 채팅' 섹션에서 '임시 채팅방'을 탭한다.
2.  '임시 채팅방' 화면으로 이동하여 다른 사용자들과 대화를 나눈다.
3.  이 채팅방은 위치와 상관없이 누구나 참여할 수 있다.

---

### 7. 프로필 관리

**Actor:** 자신의 프로필 정보를 확인하고 싶은 사용자

**Goal:** 자신의 프로필 화면으로 이동하여 이름과 사진을 확인하고 로그아웃한다.

**시나리오:**

1.  사용자가 메인 화면(채팅방 목록) 하단의 네비게이션 바에서 '프로필' 아이콘을 탭한다.
2.  '프로필' 화면으로 이동한다.
3.  화면에는 사용자의 Google 계정 이름과 프로필 사진이 표시된다.
4.  사용자가 '로그아웃' 버튼을 탭하면 확인 팝업이 나타난다.
5.  '확인'을 누르면 로그아웃 처리되고 '로그인' 화면으로 이동한다.
